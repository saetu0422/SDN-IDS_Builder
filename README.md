# SDN-IDS_Builder

이 프로젝트는 **GPT를 활용하여 제작하였습니다.**

Assembly — SDN IDS Studio

알고리즘 선택 → 구조도 연결 및 규격 검사 → PyTorch 코드 생성 → 실제 학습·검증을 수행하는 로컬 MVP입니다.

## 실행

```powershell
python app.py
```

브라우저에서 http://127.0.0.1:8787 을 엽니다. 웹 서버 자체는 Python 표준 라이브러리만 사용합니다.
실험 실행에는 `torch>=2.2`, `numpy>=1.24`가 필요합니다. 현재 개발 환경에는 설치되어 있습니다.
다른 환경에서는 `python -m pip install -r requirements.txt`로 설치합니다.

## 제공 기능

- Conv1D, LSTM, self attention 블록 추가·삭제·순서 변경 (최대 6개)
- 기본 분류기 / 선택된 expert만 실행하는 top-1 MoE, Adam / RAdam 선택
- 특성 수·시퀀스 길이·epoch·seed 설정, 선택 설정 브라우저 저장
- 노드별 입출력 shape 표시, pooling 누락 시 분류기 노드에 오류 및 수정 방법 표시
- 생성된 Python 코드 미리보기·복사 및 독립 실행 프로젝트 ZIP 다운로드
- 합성 데이터로 실제 CPU 학습, 검증 F1 기반 체크포인트 선택, 독립 테스트 평가
- F1-macro·클래스별 recall·CPU batch 1 p50/p95/p99 지연 선택
- 실행 당시 설정·환경·학습 이력·실행 로그 표시
- `runs/<실행 ID>/`에 코드·설정·results.json·model.pt·scaler.npz 저장

Mean pooling을 해제해 연결 오류를 확인한 뒤 다시 연결하면 정상 실행할 수 있습니다.
검증 결과는 마지막 실행의 설정과 함께 표시됩니다. 설정 변경 시 새 검증을 실행하세요.

## 실제 데이터

내보낸 프로젝트에서 `python train.py --data flows.npz`를 실행합니다.
NPZ에는 `X_train`, `X_val`, `X_test` 배열 `[N, sequence, features]`와
`y_train`, `y_val`, `y_test` 정수 배열 `[N]`가 필요합니다.
각 분할은 0=Benign, 1=Scan, 2=Flood 세 클래스를 포함해야 합니다.
세션/시간 단위로 먼저 분리하고 윈도우를 구성하세요. 정규화는 학습 데이터에만 맞춥니다.

## 범위

합성 데이터 지표는 코드 실행 점검용입니다. 운영 IDS 성능을 나타내지 않습니다.
웹 UI에서 실제 CSV 업로드·열 선택·학습·평가를 지원합니다.
패킷 수집, SDN 컨트롤러 연결, SparseGPT, 임의 DAG, 논문·이미지 해석은 포함하지 않습니다.
연결은 순차 파이프라인으로 제한합니다. MoE의 속도 향상은 보장하지 않습니다.
서버 재시작 시 UI 실행 기록은 초기화되지만 runs 파일은 유지됩니다.
폰트는 인터넷 연결 시 Google Fonts를 사용하며, 오프라인에서는 시스템 글꼴로 표시됩니다.

## 검증

```powershell
python -m unittest discover -s tests -v
```

기본 조합·MoE·입력 오류·shape 오류·지표 계산·NPZ 로딩을 검증합니다.
포트 변경: `python app.py --port 8788`.

## CSV 업로드로 학습하기

1. 화면 위 **CSV 파일**에서 파일을 업로드합니다. 한 행은 하나의 Flow입니다.
2. **라벨 열**을 고르고 **입력 특성** 체크박스를 선택합니다. 라벨·그룹 열은 특성에서 제외됩니다.
3. 클래스 비율 유지 무작위 분할 또는 세션 열을 사용하는 그룹 분리를 선택합니다.
4. **검증 실행**을 누르면 선택 데이터로 실제 학습하고, 검증 F1로 모델을 선택한 뒤 테스트합니다.

제한: UTF-8/CP949 CSV·TSV, 최대 50MB·200,000행·128열, 숫자 특성 1~64개,
라벨 2~50개 클래스, 클래스별 최소 7행. CSV 입력은 시퀀스 길이 1로 고정됩니다.
결측값·무한대·문자 특성은 자동 보정하지 않으며 선택 불가능합니다.
시간적 시퀀스 학습은 기존 NPZ CLI 경로를 사용하세요.

기본 분할은 클래스별 목표 70/15/15 (정수 반올림 차이 가능)입니다.
그룹 분리는 그룹 수 기준 목표 70/15/15이며 행 비율은 다를 수 있습니다.
그룹 분할 후 어느 분할에 클래스가 빠지면 오류를 표시하며 무작위 행 분할로 자동 대체하지 않습니다.
정규화의 평균·표준편차는 학습 데이터만으로 계산합니다.
같은 세션의 Flow가 여러 행에 존재하면 그룹 분리를 사용하세요.

업로드 원본과 메타데이터는 `uploads/`에, 실행 결과는 `runs/`에 로컬 저장됩니다.
ZIP에는 선택 데이터의 분할 파일 `flows.npz`, 클래스 및 분할 설명 `dataset_report.json`,
분할에 사용된 레코드 번호 `split_rows.json`도 포함됩니다. 실제 데이터가 포함된 ZIP입니다.
결과 화면은 원본 파일 해시·선택 특성·라벨·클래스별 분할 수를 보여줍니다.
`examples/upload-demo.csv`는 업로드 동작 확인을 위한 인공 예제이며 실제 SDN 수집 데이터가 아닙니다.

서버 실행 후 API 통합 검사: `python tests/http_smoke.py`.

## 여러 모델 실험 비교

구조도에서 데이터·특성·라벨·분할·seed·학습 설정을 정한 뒤 **실험 비교** 탭을 엽니다.
CNN, LSTM, Attention, 이들의 MoE 조합 중 2~8개를 선택하거나 현재 구조도를 후보에 추가합니다.
모든 후보는 동일 optimizer·epoch·seed를 사용하며, 지표 선택과 관계없이 F1-macro,
클래스별 재현율, p50/p95/p99 추론 지연을 모두 측정합니다.

CSV는 한 번 분할한 `flows.npz`를 모든 실험에 그대로 복사합니다.
공통 데이터 지문과 클래스별 분할을 기록하며, 각 모델은 CPU 2 threads에서 순차 실행합니다.
합성 모드는 같은 seed·크기와 고정 생성 코드로 동일 데이터를 재생성합니다.
지연은 batch 1·warmup 30·측정 200회이며, 전처리 및 네트워크는 제외됩니다.

비교표는 완료된 모델의 최고 F1와 최저 p95를 강조하고, 실패 상태·설정·로그도 표시합니다.
**비교표 CSV**로 수치를 내보낼 수 있습니다. 비교 기록은 `runs/comparisons/`에 저장되며
새로고침·서버 재시작 후 기록 선택에서 다시 볼 수 있습니다. 실행 중 서버를 종료한 기록은
중단 상태가 됩니다. 자동 재실행은 하지 않습니다.

단일 seed의 결과이며 시스템 부하·실행 순서의 영향이 남습니다.
테스트 비교표로 반복 튜닝한 최종 모델은 별도 보류 데이터로 검증하세요.
CSV 시퀀스 길이는 1이므로 LSTM/attention의 장기 시계열 성능 비교를 의미하지 않습니다.
인공 CSV 4개 모델 실제 통합 검사: `python tests/compare_http_smoke.py`.
